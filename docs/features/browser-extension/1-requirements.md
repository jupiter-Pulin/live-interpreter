# Requirements: 会议同传浏览器插件

## Summary

用户在 Google Meet 等网页会议中，点浏览器右上角的扩展图标弹出「会议同传」面板，点「开启同传」：插件冷启动本地翻译服务并连接会议音频，界面分步转圈，全部就绪后弹出系统通知「同传已就绪」并写明两方向将如何翻译。开启后：对方说的翻成我想听的语言进耳机、我说的任意支持语言翻成「对方听的语言」送进会议；翻译播放时原声压低、停顿时恢复，不会无声。我在 Meet 里点静音，插件随之暂停翻译我的话、继续翻译对方。点插件里的「关闭同传」才是真正关闭：翻译与本地服务结束，但对方原声继续进我的耳机、我的原声继续进会议。不自动连接，一切从我点「开启同传」开始。面板照 `design/extension/Main.dc.html`（弹窗）与 `Docked.dc.html`（侧栏）实现；BlackHole 路由放选项页。网页版不再保留。

> **2026-09-10 实机反馈变更**：①「关闭同传」、开启途中取消、任何失败都释放麦克风与全部音频设备，插件在非开启状态下不占麦（macOS 橙色指示消失）；「断开会议音频」入口与「原声直通中」状态取消。代价：关闭后插件不再转送声音，会议麦克风若仍选着 BlackHole 16ch，对方听不到你。②开启中主按钮为「取消开启」，可随时取消。下文已按此更新；工程契约见 `2-tech-spec.md` 的 AC-146～AC-150。

## Problem

现在要用同传得先在终端起服务、打开 `localhost:5173`、手动核对四个设备角色、分别点「启动下行」「启动上行」再「解除静音」。会议里临时需要翻译时步骤太多。更根本的是：会议的扬声器和麦克风都指向 BlackHole，插件一旦不在搬运音频，会议就既听不到对方、对方也听不到我；我在 Meet 里静音后插件还在把我的话送去翻译——既浪费，也把旁边的谈话送了出去。旧代码还把「对方听英语」写死，实际 API 支持 13 种输出语言。

## Users / Consumers

| Consumer | Need | Notes |
| --- | --- | --- |
| 在网页会议中需要实时翻译的用户（本人） | 一键开同传、看得到启动进度和就绪提示；Meet 静音即停翻自己的话；关闭后会议照常 | macOS + Chrome，已装 BlackHole 2ch/16ch，建议耳机 |
| 开发者（本人） | mock 后端零成本验证整条链路；真实后端用同一扩展 | 复用现有 `TRANSLATE_BACKEND` 与 `.env` |

## Goals

- MUST 只有用户点「开启同传」才连接会议音频并冷启动本地翻译服务；不自动连接，浏览器启动后不占用麦克风。
- MUST 开启过程分步转圈（连接会议音频 → 启动本地翻译服务 → 连接翻译服务），两方向都就绪后才算开启成功，并弹出系统通知「同传已就绪」，内容准确写明两方向将如何处理（含「你在会议里已静音」的情形）；失败也弹通知说明原因。
- MUST 开启后翻译叠在原声上：翻译播放时原声压到 25%（可选 0% / 50%），停顿 ≥ 0.7 s 恢复 100%；任何状态不出现无声。
- MUST 在 Google Meet 网页里点静音 → 插件暂停翻译我的话（不再送麦克风音频给翻译服务、丢弃并清空我的译文、我的原声保持），对方的接收与翻译不受影响；取消静音即恢复；非 Meet 平台无法感知则不暂停并明示。
- MUST 「关闭同传」只结束翻译与本地服务：对方原声继续进我的耳机，我的原声继续进会议，零费用。
- MUST 关闭同传、开启途中取消、任何失败之后，插件不占用麦克风与任何音频设备；会议音频连接失败与翻译失败分开显示。
- MUST 开启中可随时点「取消开启」，立即回到「同传已关闭」，不发通知。
- MUST 不需要声明自己说什么语言；面板只选「你想听的语言」「对方听的语言」，各为 13 种输出语言之一或「原声（不翻译）」；记住选择，默认中文 / English。
- MUST 会议页面不出现任何翻译文字、不被注入任何 UI；Meet 静音探测脚本只读麦克风按钮状态。
- MUST 移除网页版入口；扩展仍在用的公共能力保留。
- SHOULD 面板可停靠为侧栏；选项页提供设备角色、麦克风授权、衬底音量、本地服务自检。

## Non-goals

- 不改变音频路由方案：仍需两块 BlackHole + 多输出设备，手动安装。
- 不做插件自带的静音按钮：静音就是 Meet 的静音。
- 不感知 Zoom / Teams 等其它平台的静音（后续可加探测适配）。
- 不消除「每句开头 1–2 s 原声尚未压低」（翻译延迟所致）。
- 不做自动连接、不做自动重连（暂停期间上行挂起后按需重建、设备变化后重试除外）。
- 不在面板显示字幕与延迟数字（设计 v2 无此区域）。
- 不发布到 Chrome Web Store；不支持 Windows / Linux / 非 Chromium。
- 不保留网页版作为调试面。

## Upstream Limits

| Limit | Detail | Product consequence |
| --- | --- | --- |
| 输入语言自动识别 | 「automatically detects the source language」，70+ 种；无指定输入语言的字段 | 面板不提供「你说的语言」 |
| 输出语言 13 种 | English, Spanish, Portuguese, French, German, Italian, Russian, Chinese, Japanese, Korean, Hindi, Indonesian, Vietnamese；`session.audio.output.language` | 两个下拉只列这 13 种 |
| 每个目标语言一个会话 | 「Create one translation session for each target language」 | 下行、上行各一个会话；改目标语言 = 重建该方向会话 |
| 同语言片段不出声 | 「tries not to translate speech that is already in the selected output language … may not produce translated audio」 | 衬底「翻译停顿即恢复原声」使这些片段听到原声而非无声 |
| 官方建议保留原声并在译文播放时压低 | 「keep the original audio available」「duck the original audio while translated audio is playing」 | 本版即按此实现 |
| 翻译延迟 | 译文比原声晚 1–2 s | 每句开头先听到一段未压低的原声 |
| 计费按送入音频时长 | $0.034 / 分钟 | 静音期间停止送音即不计费；原声方向（选「原声」）不计费 |
| 会话时长 / 空闲超时 | 未说明 | 暂停期间上行会话若被关闭，恢复时自动重建 |
| 扩展感知会议静音的唯一途径 | 读会议页面 DOM（Chrome 扩展模型） | 只能为 Meet 做只读探测；其它平台「未知」 |

## User Scenarios

| Scenario | Given | When | Then |
| --- | --- | --- | --- |
| 浏览器刚启动 | 已安装、已授权 | 不做任何操作 | 插件不占麦克风、不连接；图标无角标；弹窗「同传已关闭」 |
| 一键开启（冷启动） | 未连接，在 Meet 会议中 | 点「开启同传」 | 按钮转圈，下方依次显示「正在连接会议音频…」「正在启动本地翻译服务…」「正在连接翻译服务…」；两方向就绪后标题「同传进行中」（脉冲绿点），图标绿点，并弹系统通知「同传已就绪：对方说的会翻成中文进你的耳机，你说的话会翻成 English 送进会议。」 |
| 开启时已在 Meet 静音 | 未连接，Meet 已静音 | 点「开启同传」 | 就绪通知写明「你在会议里已静音，取消静音后你说的话会翻成 English 送进会议」；面板显示「会议已静音 · 暂停翻译你的话」 |
| 翻译时听感 | 同传进行中 | 对方说英语 | 先听到原声，译文播放时原声压到 25%，译文停顿后原声回 100% |
| 对方说的就是我想听的语言 | 同传进行中，你想听的语言 = 中文 | 对方说中文 | 模型不出声，原声保持 100% |
| Meet 静音 | 同传进行中，Meet 未静音 | 在 Meet 点麦克风静音 | 0.5 s 内面板出现「会议已静音 · 暂停翻译你的话」，图标变琥珀点；我的话不再送去翻译，已在播的译文立即停止；对方的翻译继续进耳机 |
| Meet 取消静音 | 会议已静音 | 在 Meet 取消静音 | 立即恢复翻译我的话；若暂停期间上行会话被关闭，自动重建（面板短暂「正在恢复翻译…」） |
| 非 Meet 平台 | 同传进行中，会议在 Zoom 网页 | 在 Zoom 静音 | 插件无法感知，翻译照常；面板常显「未感知到会议静音（仅支持 Google Meet）」 |
| 弹窗关闭 | 同传进行中 | 关闭弹窗 | 翻译不中断；再点图标仍是「同传进行中」 |
| 关闭同传 | 同传进行中 | 点「关闭同传」 | 翻译、本地服务、麦克风与音频设备全部释放；标题「同传已关闭」；橙色麦克风指示消失；图标无角标 |
| 开启途中取消 | 正在开启（任一步） | 点「取消开启」 | 立即回到「同传已关闭」，已建的连接与本地服务全部撤掉，不发通知；可马上重新开启 |
| 再次开启 | 同传已关闭 | 点「开启同传」 | 重新走三步冷启动，就绪后通知 |
| 改「你想听的语言」（进行中） | 同传进行中 | 选 日本語 | 下行以日语重新开始，上行不受影响 |
| 改「对方听的语言」（进行中） | 同传进行中 | 选 Español | 上行以西语重新开始；静音暂停状态保持 |
| 某方向选「原声（不翻译）」 | 任意 | 「对方听的语言」选原声 | 该方向不建翻译会话、不计费，原声 100% |
| 翻译失败 | 任意 | 开启时本地服务未安装 / 无网络 | 面板「无法开启同传」+ 原因；系统通知同样内容；麦克风已释放 |
| 会议音频连接失败 | 缺一块 BlackHole / 未授权 / 耳机未接 | 点「开启同传」 | 第一步即失败：面板「无法连接会议音频」（红）+ 原因 + 「开启同传」/「音频设置」/「去授权麦克风」；通知说明会议此刻听不到你、你也听不到会议 |
| 停靠侧栏 | 弹窗打开 | 点「停靠到侧栏」 | 面板出现在会议右侧，弹窗关闭，内容一致 |

## Product Rules

| Rule | Priority | Notes |
| --- | --- | --- |
| 不自动连接；连接、占用麦克风只发生在用户点「开启同传」之后 | MUST | 用户决定 |
| 开启 = 冷启动：连接会议音频 → 启动本地翻译服务 → 连接翻译服务；每步有文案，整体转圈 | MUST | 已连接时跳过第一步 |
| 就绪判定 = 桥已连接且每个翻译方向的会话已打开、采集已启动；此刻才弹「同传已就绪」通知与切换状态 | MUST | 通知内容按实际计划与静音态生成 |
| 开启失败弹通知说明原因；桥失败与翻译失败分开 | MUST | 无 |
| 原声是底，翻译是顶：同传进行中任何时刻不断声 | MUST | 核心体验 |
| 非开启不占用：关闭、取消、失败的终态都不占用麦克风与音频设备 | MUST | 2026-09-10 变更 |
| 翻译播放时原声压到 `floorLevel`（0 / 25% / 50%，默认 25%），停顿 ≥ 0.7 s 回 100% | MUST | 用户已同意 |
| 关闭同传 = 撤掉翻译、本地服务与会议音频连接 | MUST | 2026-09-10 变更 |
| 翻译失败只影响翻译层；桥失败时翻译一并停止 | MUST | 无 |
| Meet 静音 = 暂停翻译我的话：不送麦克风音频、丢弃并清空我的译文、我的原声保持；下行不变 | MUST | 只读探测 `data-is-muted` |
| 暂停期间上行会话保持；被对端关闭则恢复时重建 | MUST | 无 |
| 静音态未知（无 Meet 页、探测失败、其它平台）→ 不暂停并明示 | MUST | 退化安全 |
| 「你想听的语言」= 下行目标；「对方听的语言」= 上行目标；不提供「你说的语言」 | MUST | 13 种 + 原声 |
| 某方向选「原声」→ 不建会话、不采集、原声 100% | MUST | 无 |
| 改目标语言只重建受影响方向；暂停状态保持 | MUST | 无 |
| 真麦克风直通路开回声消除与降噪；BlackHole 截获路不做处理 | MUST | 外放时减少回声 |
| 面板不显示字幕/延迟 | MUST | 设计 v2 |
| 语言、设备覆盖、衬底音量持久化；运行态不持久化 | MUST | 浏览器重启后未连接 |

| 进行中（Meet 已静音） | 标题「同传进行中」；说明「会议已静音 · 暂停翻译你的话。对方说的仍会翻成{听}进你的耳机。」（琥珀色） |

| 选项页衬底 | 「同传时原声衬底」单选：关闭（翻译时只听译文）/ 低 25%（默认）/ 中 50%；说明「翻译停顿时原声总会恢复，不会无声。」 |
| 选项页静音说明 | 「在 Google Meet 里静音时会自动暂停翻译你的话；其它会议平台暂不支持感知静音。」 |
| 主题 / 字体 | 深色默认，系统浅色时用浅色 token；系统字体栈，不加载远程字体 |

## Data Semantics

| Field / Concept | Meaning | Empty / Unknown Behavior |
| --- | --- | --- |
| `hear` | 你想听的语言：13 种码之一或 `original` | 缺省/未知 → `zh` |
| `partnerHears` | 对方听的语言：13 种码之一或 `original` | 缺省/未知 → `en` |
| `floorLevel` | 翻译播放时原声音量：0 / 0.25 / 0.5 | 缺省/未知 → 0.25 |
| `deviceOverrides` | 四个设备角色的手动指定 | 缺省空 = 自动分配 |
| 运行态 `bridge` | disconnected / connecting / connected / failed | 浏览器重启后 disconnected |
| 运行态 `phase` | off / starting / on / stopping / error（翻译层） | 浏览器重启后 off |
| 运行态 `startStep` | 开启中的当前步骤：bridge / host / translation | 非开启中为 null |
| 运行态 `meetingMuted` | Meet 静音态：true / false / null（未知） | 无 Meet 页或探测失败 → null → 不暂停 |
| 上行状态 `suspended` | 暂停期间上行会话被对端关闭，等待恢复时重建 | 恢复后回到 running |
